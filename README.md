# i3-cursor-focus
Small python script to change the behavior of i3 cursor, using the i3ipc library and xdotools.

## Installation
Clone the repo in your .local/share and add this line to your i3 config:
``` exec_always --no-startup-id ~/.local/share/i3-cursor/venv/bin/python ~/.local/share/i3-cursor/i3-focus.py ```
